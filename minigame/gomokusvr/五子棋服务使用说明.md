# 五子棋服务使用说明

## 🎯 服务概述

五子棋服务(gomokusvr)是一个完整的多人在线五子棋游戏后端服务，玩家通过网关服务器(gatesvr)接入，可以创建房间、加入房间、下棋对战等。

## 🚀 快速启动

### 1. 启动依赖服务

**启动Nacos服务器**：
```bash
# 下载并启动Nacos (Docker方式)
docker run --name nacos-standalone -e MODE=standalone -e JVM_XMS=512m -e JVM_XMX=512m -e JVM_XMN=256m -p 8848:8848 -d nacos/nacos-server:v2.2.3
```

**启动网关服务**：
```bash
cd gatesvr
go run cmd/main.go
```

### 2. 启动五子棋服务

```bash
cd minigame/gomokusvr
go run cmd/main.go
```

服务启动后将看到类似输出：
```

成功加载配置文件: config.yaml
配置加载完成: {Server:{Name:gomokusvr Port:50052 Host:localhost} ...}
房间管理器初始化完成
Nacos客户端初始化成功
服务注册成功 - 服务名: gomokusvr, IP: 192.168.1.100, 端口: 50052
五子棋服务已启动，监听端口: 50052
```

## 🎮 游戏流程

### 完整对战流程

1. **玩家A创建房间**
2. **玩家B加入房间**
3. **房主开始游戏**
4. **玩家轮流下棋**
5. **胜负判断或游戏结束**

## 🔌 客户端接入

### 消息格式

所有消息都通过gatesvr转发，使用以下格式：

```json
{
  "head": {
    "msg_id": "unique_message_id",
    "player_id": "player_123",
    "service_name": "gomokusvr",
    "method": "CreateRoom"
  },
  "msg_type": 1,
  "payload": "<protobuf_encoded_data>",
  "timestamp": 1703123456789
}
```

### 支持的方法

| 方法名 | 功能 | 说明 |
|--------|------|------|
| `CreateRoom` | 创建房间 | 玩家创建游戏房间 |
| `JoinRoom` | 加入房间 | 加入指定房间 |
| `LeaveRoom` | 离开房间 | 离开当前房间 |
| `DestroyRoom` | 销毁房间 | 房主销毁房间 |
| `StartGame` | 开始游戏 | 房主发起游戏开始 |
| `PlacePiece` | 下棋 | 在指定位置下棋 |
| `GetRoomList` | 房间列表 | 获取可用房间列表 |

## 🎯 API详细说明

### 1. 创建房间

**请求**：
```json
{
  "room_name": "我的房间",
  "password": "123456"  // 可选，房间密码
}
```

**响应**：
```json
{
  "success": true,
  "room_id": "a1b2c3d4",
  "message": "房间创建成功"
}
```

### 2. 加入房间

**请求**：
```json
{
  "room_id": "a1b2c3d4",
  "password": "123456"  // 如果房间有密码
}
```

**响应**：
```json
{
  "success": true,
  "message": "加入房间成功",
  "room_info": {
    "room_id": "a1b2c3d4",
    "room_name": "我的房间",
    "status": 0,  // 0=等待, 1=游戏中, 2=已结束
    "players": [
      {
        "player_id": "player_123",
        "username": "玩家1",
        "color": 1,     // 1=黑子, 2=白子
        "is_ready": true,
        "join_time": 1703123456789
      }
    ],
    "owner_id": "player_123",
    "created_time": 1703123456789
  }
}
```

### 3. 开始游戏

**请求**：
```json
{
  "room_id": "a1b2c3d4"
}
```

**响应**：
```json
{
  "success": true,
  "message": "游戏开始",
  "game_state": {
    "board": [0, 0, 0, ...],  // 225个元素，15x15棋盘
    "current_turn": 1,        // 1=黑子回合, 2=白子回合
    "result": 0,              // 0=进行中, 1=黑子胜, 2=白子胜, 3=平局
    "winner_id": "",
    "total_moves": 0,
    "move_history": []
  }
}
```

### 4. 下棋

**请求**：
```json
{
  "room_id": "a1b2c3d4",
  "x": 7,    // X坐标 (0-14)
  "y": 7     // Y坐标 (0-14)
}
```

**响应**：
```json
{
  "success": true,
  "message": "下棋成功",
  "game_state": {
    "board": [0, 0, 1, ...],  // 更新后的棋盘
    "current_turn": 2,        // 切换到对手回合
    "result": 0,              // 游戏结果
    "total_moves": 1,
    "move_history": [
      {
        "player_id": "player_123",
        "color": 1,
        "x": 7,
        "y": 7,
        "move_number": 1,
        "timestamp": 1703123456789
      }
    ]
  }
}
```

### 5. 获取房间列表

**请求**：
```json
{
  "page": 1,
  "page_size": 10
}
```

**响应**：
```json
{
  "success": true,
  "rooms": [
    {
      "room_id": "a1b2c3d4",
      "room_name": "我的房间",
      "status": 0,
      "players": [...],
      "owner_id": "player_123",
      "created_time": 1703123456789
    }
  ],
  "total_count": 5,
  "message": "获取房间列表成功"
}
```

## 🎲 游戏规则

### 基本规则
- **棋盘**：15×15网格
- **棋子**：黑子和白子
- **先手**：黑子先下
- **获胜条件**：在横、竖、斜任一方向连成5子
- **平局**：棋盘下满无人获胜

### 坐标系统
```
   0 1 2 3 4 ... 14
0  . . . . .     .
1  . . . . .     .
2  . . . . .     .
3  . . . . .     .
4  . . . . .     .
...
14 . . . . .     .
```

### 棋盘表示
- 棋盘使用一维数组表示，长度225（15×15）
- 坐标(x,y)对应数组索引：`index = x * 15 + y`
- 数组值：`0=空位`, `1=黑子`, `2=白子`

## 🔧 错误处理

### 常见错误码

| 错误码 | 含义 | 解决方案 |
|--------|------|----------|
| 400 | 参数错误 | 检查请求参数格式 |
| 500 | 服务器错误 | 查看服务器日志 |
| 1001 | 房间不存在 | 确认房间ID正确 |
| 1002 | 房间密码错误 | 输入正确密码 |
| 1003 | 房间已满 | 选择其他房间 |
| 1004 | 不是你的回合 | 等待对手下棋 |
| 1005 | 位置已有棋子 | 选择空白位置 |

### 错误响应格式
```json
{
  "success": false,
  "message": "房间不存在",
  "code": 1001
}
```

## 🆘 常见问题

**Q: 服务启动失败，提示Nacos连接错误？**
A: 确保Nacos服务器正在运行，检查配置文件中的server_addr设置。

**Q: 玩家下棋提示"不是你的回合"？**
A: 检查当前轮次，五子棋是回合制游戏，需要等待对手下棋。

**Q: 房间列表为空？**
A: 确保有其他玩家创建了房间，房间会在一定时间后自动清理。

**Q: 如何实现断线重连？**
A: 客户端需要记录房间ID，重连后重新加入房间即可。
