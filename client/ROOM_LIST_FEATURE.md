# 房间列表显示功能

## 功能概述

为五子棋GUI客户端添加了完整的房间列表显示功能，用户可以通过图形界面查看所有可用房间，并直接加入房间。

## 主要功能

### 1. 房间列表窗口
- 📋 **表格式显示**：使用Treeview控件展示房间信息
- 🔍 **详细信息**：显示房间ID、名称、玩家数、状态、密码信息
- 📊 **实时状态**：区分等待中、游戏中、已结束状态
- 🎯 **直观界面**：清晰的图标和颜色标识

### 2. 房间信息显示

#### 显示列
| 列名 | 内容 | 说明 |
|------|------|------|
| 房间ID | room_001 | 房间唯一标识 |
| 房间名称 | 新手房间 | 房间显示名称 |
| 玩家数 | 1/2 | 当前/最大玩家数 |
| 状态 | ⏳ 等待中 | 房间当前状态 |
| 密码 | 🔒 有密码 | 密码保护状态 |

#### 状态图标
- ⏳ **等待中**：房间在等待玩家加入
- 🎮 **游戏中**：房间正在进行游戏
- 🏁 **已结束**：游戏已结束
- 🔒 **有密码**：需要密码才能加入
- 🔓 **无密码**：可直接加入

### 3. 交互功能

#### 加入房间
- **单击选择** + **点击按钮**：选中房间后点击"加入选中房间"
- **双击快速加入**：双击房间行直接加入
- **密码处理**：自动检测并提示输入房间密码

#### 操作按钮
- 🚀 **加入选中房间**：加入当前选择的房间
- 🔄 **刷新列表**：提示用户重新获取房间列表
- ❌ **关闭**：关闭房间列表窗口

## 使用方法

### 基本操作流程
1. **连接服务器**：确保客户端已连接到游戏服务器
2. **获取房间列表**：点击主界面的"房间列表"按钮
3. **浏览房间**：在弹出的窗口中查看所有可用房间
4. **选择房间**：单击选择要加入的房间
5. **加入房间**：
   - 方式1：点击"加入选中房间"按钮
   - 方式2：双击房间行
6. **密码处理**：如果房间有密码，会自动弹出密码输入框

## 错误处理

### 连接检查
- 加入房间前检查服务器连接状态
- 连接断开时显示错误提示

### 密码处理
- 自动检测房间是否需要密码
- 用户取消密码输入时不执行加入操作
- 密码错误时显示服务器返回的错误信息

### 异常处理
- 窗口创建失败时的错误提示
- 数据解析异常的处理
- 网络请求失败的处理
