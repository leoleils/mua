# 五子棋GUI客户端 - 优化版本

## 🎮 概述

这是一个基于tkinter的五子棋GUI客户端，经过全面优化，提供了完整的游戏功能和用户体验。

## 🔧 新增功能

### 1. 完整的响应处理器
- ✅ **创建房间响应** - 显示房间ID和状态
- ✅ **加入房间响应** - 显示房间信息和玩家列表
- ✅ **离开房间响应** - 清理本地状态
- ✅ **销毁房间响应** - 完整的房间清理
- ✅ **玩家准备响应** - 实时准备状态更新
- ✅ **开始游戏响应** - 游戏状态初始化
- ✅ **下棋响应** - 棋盘状态更新
- ✅ **获取房间列表响应** - 格式化房间列表显示

### 2. 详细的推送通知显示
- 🔔 **游戏操作通知** - CreateRoom、JoinRoom、LeaveRoom等
- 🔔 **棋子放置通知** - 对手下棋实时提醒
- 🔔 **游戏状态变化通知** - 游戏开始、结束、状态变化
- 🔔 **玩家事件通知** - 玩家加入、离开、准备状态变化
- 🔔 **系统消息处理** - 认证失败、被踢下线等

### 3. 实时状态显示
- 🏠 **当前房间** - 显示房间ID，绿色表示已加入
- ⏳ **准备状态** - 显示准备状态，蓝色表示已准备
- 🎮 **游戏状态** - 显示游戏进行状态，橙色表示进行中
- 🔄 **自动刷新** - 状态变化时自动更新显示

### 4. 增强的房间管理
- 🏠 **创建房间** - 支持房间名和密码设置
- 🚪 **加入房间** - 支持房间ID和密码输入
- 📋 **房间列表** - 格式化显示房间信息
- 🚶 **离开房间** - 安全离开当前房间
- 🏚️ **销毁房间** - 销毁自己创建的房间

### 5. 密码支持
- 🔒 **创建房间密码** - 可选的房间密码保护
- 🔓 **加入房间密码** - 输入密码加入受保护的房间
- 🔑 **密码验证** - 服务器端密码验证

### 6. 更好的错误处理
- 🔌 **连接状态检查** - 操作前检查连接状态
- 🏠 **房间状态验证** - 确保在正确的房间状态下操作
- 🎮 **游戏状态验证** - 下棋前检查游戏状态
- ⚠️ **用户友好提示** - 清晰的错误提示和警告

### 7. 线程安全日志
- 📝 **多线程支持** - 支持从不同线程安全地记录日志
- 🔄 **自动滚动** - 日志自动滚动到最新消息
- 📊 **日志限制** - 防止日志过多影响性能
- 🧹 **清空日志** - 一键清空日志内容

## 🚀 使用方法

### 1. 启动GUI
```bash
python gomoku_gui.py
# 或者
python test_gui_optimized.py
```

### 2. 连接服务器
1. 输入玩家ID（可使用默认生成的ID）
2. 输入服务器地址（默认: 127.0.0.1:6001）
3. 点击"连接"按钮

### 3. 房间管理
- **创建房间**: 点击"创建房间"，输入房间名和密码（可选）
- **加入房间**: 点击"加入房间"，输入房间ID和密码（如果有）
- **查看房间列表**: 点击"房间列表"查看所有可用房间
- **离开房间**: 点击"离开房间"安全退出当前房间
- **销毁房间**: 点击"销毁房间"删除自己创建的房间

### 4. 游戏操作
- **准备游戏**: 点击"准备"按钮切换准备状态
- **开始游戏**: 点击"开始游戏"开始游戏（需要双方都准备）
- **下棋**: 点击棋盘上的交叉点进行下棋
- **查看状态**: 实时状态显示在左侧面板

## 🎯 界面说明

### 左侧面板
- **连接设置**: 玩家ID、服务器地址、连接按钮
- **房间管理**: 创建、加入、列表、离开、销毁按钮
- **游戏控制**: 准备、开始游戏按钮
- **当前状态**: 房间状态、准备状态、游戏状态显示
- **消息日志**: 所有操作和通知的详细日志

### 右侧棋盘
- **15x15棋盘**: 标准五子棋棋盘
- **点击下棋**: 点击交叉点进行下棋
- **实时更新**: 对手下棋后自动更新显示

## 🔔 通知系统

### 响应通知
- 创建房间成功时显示房间ID
- 加入房间成功时显示房间信息和玩家列表
- 操作失败时显示详细错误信息

### 推送通知
- 对手下棋时实时提醒
- 其他玩家加入/离开房间时通知
- 游戏状态变化时及时更新
- 玩家准备状态变化时通知

## 📋 状态显示

### 房间状态
- 灰色: 未加入房间
- 绿色: 已加入房间（显示房间ID）

### 准备状态
- 灰色: 未准备
- 蓝色: 已准备

### 游戏状态
- 灰色: 未开始
- 橙色: 游戏进行中（显示当前玩家）
- 红色: 游戏结束（显示结果）

## 🎮 游戏流程

1. **连接服务器** - 输入玩家ID和服务器地址
2. **创建或加入房间** - 创建新房间或加入已有房间
3. **准备游戏** - 双方玩家都需要点击准备
4. **开始游戏** - 任一玩家点击开始游戏
5. **下棋对战** - 轮流在棋盘上下棋
6. **游戏结束** - 五子连珠或平局时游戏结束

## 💡 提示

- 所有操作都会在日志中显示详细信息
- 状态显示会自动更新，无需手动刷新
- 支持多个房间同时存在
- 密码保护的房间会显示🔒图标
- 可以随时查看房间列表了解当前状态

## 🐛 故障排除

### 连接问题
- 检查服务器地址是否正确
- 确认gomokusvr服务正在运行
- 检查网络连接

### 房间问题
- 确认房间ID正确
- 检查房间密码
- 确认房间未满员

### 游戏问题
- 确认双方都已准备
- 检查是否轮到自己下棋
- 确认下棋位置未被占用
